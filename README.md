# ロボット省人化シミュレーター

ロボット導入前後の作業時間・人件費・運用費用から、省人化効果と投資回収期間を試算するシンプルなWebアプリです。

## 使い方

GitHub Pagesで公開すると、ブラウザから利用できます。`index.html` を開き、現在の作業状況とロボット導入条件を入力してください。結果は入力に合わせてリアルタイムに更新されます。

## 試算項目

- 月間の人手作業削減時間
- 月間人件費削減額
- ロボット月額運用費を差し引いた月間純削減額
- 年間純削減額
- 初期導入費用の回収期間

## 公開方法

GitHubリポジトリの Settings → Pages で、Deploy from a branch / `main` / `/ (root)` を選択して保存してください。

※ 試算は入力条件に基づく概算です。実際の導入判断では、現場での稼働率・停止時間・教育費なども確認してください。
